# Pokémon Legends: Z-A Support — Updated 08 Aug 2026

LibreDex ships **all** Pokémon Legends: Z-A content **including** the Mega Dimension DLC (released **10 Dec 2025**).

## Mega Dimension DLC — what we bundle

- Story: Hyperspace Lumiose (Hoopa + Ansha) — accessible after Main Quest #37.
- **19 new Mega Evolutions** bundled as overlay forms `10278–10326`:
  `Mega Raichu X/Y`, `Mega Chimecho`, `Mega Baxcalibur`, `Mega Zeraora`,
  `Mega Absol Z`, `Mega Garchomp Z`, `Mega Lucario Z`, `Mega Heatran`,
  `Mega Darkrai`, `Mega Golurk`, `Mega Golisopod`, `Mega Glimmora`,
  `Mega Scovillain`, `Mega Staraptor`, `Mega Meowstic (M/F)`,
  `Mega Crabominable`, `Mega Magearna (+ Original Color)`, `Mega Tatsugiri ×3`.
  Plus all 27 base Z-A megas (Clefable, Victreebel, Starmie, Dragonite, Meganium, Feraligatr, Skarmory, Froslass, Emboar, Excadrill, Scolipede, Scrafty, Eelektross, Chandelure, Chesnaught, Delphox, Greninja, Pyroar, Floette Eternal, Malamar, Barbaracle, Dragalge, Hawlucha, Zygarde, Drampa, Falinks).

- Flags: every overlay has `mega` + `legendsZA`; Champions-legal ones also have `champions`.

## Effort Levels vs Natures

Legends: Z-A uses Effort Levels, not direct stat growth. LibreDex notes this in NatureDex (tablet/mobile cards) and keeps the `+10% / −10%` display for comparability with Champions/mainline.
