# Pokémon Legends: Z-A Support

LibreDex is fully prepared for **Pokémon Legends: Z-A** content, mechanics, and Mega Evolutions.

## Key Features
1. **Legends Forms**: Supports both official and provisional Mega Evolutions.
2. **Effort Level Nature Rules**: Instead of direct stat increases, natures in Legends: Z-A dictate Effort Level speeds and growth thresholds. These are noted inside the NatureDex.
3. **Mega Dimension DLC**: Features extra item and move overlays for upcoming DLC content.

## Search Aliases
Users can search the Pokédex or MoveDex directly using aliases such as:
- `Legends ZA`
- `Legends Z-A`
- `Mega`
- `New Mega`
- `Mega Raichu X`
- `Eternal Flower Floette`
