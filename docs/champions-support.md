# Pokémon Champions Custom Support

LibreDex includes full additive support for **Pokémon Champions** formats and alignments.

## Champions Custom Content
1. **Forms**: Features customized Champions Mega Evolutions and Stat Alignments loaded from `assets/data/forms_extra.json`.
2. **Abilities**: Bundles custom abilities (like Mountaineer, Wave Rider, Sponge, and Bodyguard) directly in the database.
3. **Moves**: Filters and displays special custom moves with power and accuracy configurations matching Champions rules.

## Alignment Stat Points
Natures in Pokémon Champions support customized Alignments (Physical Alignment, Special Alignment, Balanced Alignment) which focus growth multipliers into targeted bulk thresholds. These are fully supported inside the settings, calculators, and detail page views.
